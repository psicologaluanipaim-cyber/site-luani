# Site profissional de Luani dos Santos Paim

Este pacote contém a versão final do site, preparada para publicação pelo GitHub Pages.

## O que já está pronto

- todas as páginas do site
- identidade visual e funcionamento em celular e computador
- fotografias e demais arquivos
- navegação entre as páginas
- botões de WhatsApp e agendamento online
- arquivo que impede o GitHub de processar o site como um projeto Jekyll

## Como publicar

1. Crie ou acesse sua conta em https://github.com
2. Crie um repositório público com um nome simples, como site-luani
3. Extraia o arquivo ZIP deste pacote
4. Envie todos os arquivos e pastas extraídos para a raiz do repositório
5. Abra Settings e depois Pages
6. Em Build and deployment, escolha Deploy from a branch
7. Selecione a branch main e a pasta /(root)
8. Salve e aguarde a publicação

O GitHub fornecerá primeiro um endereço temporário. Quando o domínio próprio estiver comprado, ele poderá ser conectado em Settings, Pages, Custom domain.

## Domínio próprio

Depois da compra do domínio, será necessário fazer duas configurações.

1. Informar o domínio em Settings, Pages, Custom domain
2. Criar os registros DNS indicados pelo GitHub no painel da empresa em que o domínio foi comprado

Depois que o GitHub validar o domínio, ative Enforce HTTPS.

Não adicione um arquivo CNAME antes de decidir e comprar o domínio definitivo.

## Observação importante

Os endereços internos deste site foram preparados para funcionar na raiz de um domínio. Por isso, o domínio próprio deve ser conectado antes da divulgação pública. Se quiser testar no endereço temporário do GitHub, use um repositório com o nome exato usuario.github.io ou solicite a adaptação dos endereços internos ao nome do repositório.

## Atualizações futuras

Para alterar textos, valores ou informações futuramente, atualize os arquivos do site e envie novamente a versão corrigida ao mesmo repositório.
